# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub
private vulnerability reporting when available, or contact the repository
owner privately through GitHub.

Include the affected component, reproduction steps, impact, and suggested
mitigation. Do not include secrets or personal data in a report.

Janus Core can connect to local or optional remote model providers. Treat
provider configuration, internet research, datasets, and generated artifacts
as security-sensitive and review them before enabling automation.
